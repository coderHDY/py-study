# Python 异常处理（try/except）完整知识点

## 1) 为什么需要异常处理

程序运行时遇到错误会直接崩溃，异常处理让程序能优雅地应对错误，而不是直接中断。

```python
# 没有异常处理：直接崩溃
print(1 / 0)   # ZeroDivisionError: division by zero
```

---

## 2) 基本结构

```python
try:
    # 可能出错的代码
except:
    # 出错后执行的代码
```

```python
try:
    result = 1 / 0
except:
    print("出错了！")   # 捕获所有异常（不推荐）
```

---

## 3) 捕获指定异常类型

```python
try:
    result = 1 / 0
except ZeroDivisionError:
    print("除数不能为 0")
```

**捕获多种异常：**

```python
try:
    x = int(input("请输入数字："))
    result = 10 / x
except ValueError:
    print("输入的不是数字")
except ZeroDivisionError:
    print("不能除以 0")
```

**用元组同时捕获多种异常：**

```python
try:
    x = int(input())
    result = 10 / x
except (ValueError, ZeroDivisionError):
    print("输入有误或除数为 0")
```

---

## 4) 获取异常对象 `as e`

```python
try:
    result = 1 / 0
except ZeroDivisionError as e:
    print(f"错误类型：{type(e).__name__}")   # ZeroDivisionError
    print(f"错误信息：{e}")                  # division by zero
```

---

## 5) 完整结构：`try / except / else / finally`

```python
try:
    # 可能出错的代码
except SomeError:
    # 出错时执行
else:
    # 没有出错时执行（try 成功才运行）
finally:
    # 无论是否出错，最终都会执行
```

```python
try:
    f = open("data.txt", "r")
    content = f.read()
except FileNotFoundError as e:
    print(f"文件不存在：{e}")
else:
    print("读取成功：", content)
finally:
    print("执行完毕")   # 无论如何都会运行，常用于释放资源
```

---

## 6) `finally` 的典型用途：资源释放

```python
f = None
try:
    f = open("data.txt", "r")
    data = f.read()
except FileNotFoundError:
    print("文件不存在")
finally:
    if f:
        f.close()   # 保证文件一定被关闭
```

更推荐用 `with` 语句自动管理资源（见第 11 节）。

## 7) 捕获所有异常：`Exception`

```python
try:
    risky_operation()
except Exception as e:
    print(f"发生异常：{e}")
```

- `Exception` 是大多数异常的基类，能捕获几乎所有运行时错误。
- 裸 `except:` 会连 `KeyboardInterrupt`（Ctrl+C）、`SystemExit` 也捕获，不推荐。

---

## 8) 主动抛出异常：`raise`

```python
def set_age(age):
    if age < 0 or age > 150:
        raise ValueError(f"年龄不合法：{age}")
    return age

try:
    set_age(-1)
except ValueError as e:
    print(e)   # 年龄不合法：-1
```

**重新抛出当前异常：**

```python
try:
    1 / 0
except ZeroDivisionError as e:
    print("记录日志...")
    raise   # 原样重新抛出，不改变堆栈信息
```

## 9) 自定义异常类

继承 `Exception`（或其子类）创建语义化的自定义异常。

```python
class AgeError(ValueError):
    def __init__(self, age):
        super().__init__(f"年龄不合法：{age}，需在 0~150 之间")
        self.age = age

def set_age(age):
    if not (0 <= age <= 150):
        raise AgeError(age)

try:
    set_age(200)
except AgeError as e:
    print(e)          # 年龄不合法：200，需在 0~150 之间
    print(e.age)      # 200
```

## 10) 常见内置异常类型速查

| 异常 | 触发场景 |
|---|---|
| `ValueError` | 值类型正确但内容不合法，如 `int("abc")` |
| `TypeError` | 类型不对，如 `1 + "2"` |
| `ZeroDivisionError` | 除数为 0 |
| `IndexError` | 列表下标越界 |
| `KeyError` | 字典访问不存在的 key |
| `AttributeError` | 访问对象不存在的属性 |
| `FileNotFoundError` | 文件不存在 |
| `PermissionError` | 没有文件读写权限 |
| `ImportError` | 导入模块失败 |
| `ModuleNotFoundError` | 模块不存在（ImportError 子类）|
| `StopIteration` | 迭代器耗尽 |
| `RuntimeError` | 通用运行时错误 |
| `OverflowError` | 数值运算结果太大 |
| `MemoryError` | 内存不足 |
| `RecursionError` | 递归深度超限 |
| `NotImplementedError` | 抽象方法未实现，主动抛出表示"待实现" |

## 11) `with` 语句（上下文管理器）

`with` 是处理资源的推荐写法，自动在退出时调用清理逻辑，不需要手动 `finally`。

```python
# 文件操作：无论是否出错，都会自动关闭文件
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
# 离开 with 块后，f 自动关闭
```

同时管理多个资源：

```python
with open("a.txt") as f1, open("b.txt") as f2:
    data = f1.read() + f2.read()
```

---

## 12) 异常链：`raise ... from ...`

在捕获一个异常后抛出另一个异常，同时保留原始异常信息。

```python
try:
    int("abc")
except ValueError as e:
    raise RuntimeError("数据格式错误") from e
```

输出会显示两个异常及其关系，便于调试。

## 13) 结构速查

```python
try:
    pass          # 必须有
except TypeError:
    pass          # 可以有多个 except
except (ValueError, KeyError):
    pass          # 一个 except 捕获多种
except Exception as e:
    pass          # 获取异常对象
else:
    pass          # 可选：try 成功才执行
finally:
    pass          # 可选：无论如何都执行
```

执行顺序：
- 无异常：`try` → `else` → `finally`
- 有异常且被捕获：`try`（出错处停止）→ `except` → `finally`
- 有异常未被捕获：`try`（出错处停止）→ `finally` → 异常向上传播
