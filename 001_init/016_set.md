# Python Set 常用语法

## 创建

| 方法 | 作用 | 例子 |
|------|------|------|
| `{1, 2, 3}` | 直接创建集合 | `s = {1, 2, 3}` |
| `set(x)` | 将序列转为集合（自动去重） | `set([1,1,2])` → `{1, 2}` |
| `set()` | 创建空集合（不能用`{}`） | `s = set()` |

---

## 增 / 删

| 方法 | 作用 | 例子 |
|------|------|------|
| `s.add(x)` | 添加单个元素 | `s.add(4)` |
| `s.update(x)` | 添加多个元素（可传列表/集合） | `s.update([5, 6])` |
| `s.remove(x)` | 删除元素，不存在则报错 | `s.remove(1)` |
| `s.discard(x)` | 删除元素，不存在不报错 | `s.discard(99)` |
| `s.pop()` | 随机删除并返回一个元素 | `s.pop()` |
| `s.clear()` | 清空集合 | `s.clear()` |

---

## 查

| 方法 | 作用 | 例子 |
|------|------|------|
| `x in s` | 判断元素是否在集合中 | `2 in {1,2,3}` → `True` |
| `x not in s` | 判断元素是否不在集合中 | `5 not in {1,2}` → `True` |
| `len(s)` | 获取集合长度 | `len({1,2,3})` → `3` |

---

## 集合运算

| 方法 | 作用 | 例子 |
|------|------|------|
| `a \| b` 或 `a.union(b)` | 并集（两个集合所有元素） | `{1,2} \| {2,3}` → `{1,2,3}` |
| `a & b` 或 `a.intersection(b)` | 交集（共同元素） | `{1,2} & {2,3}` → `{2}` |
| `a - b` 或 `a.difference(b)` | 差集（a有b没有） | `{1,2} - {2,3}` → `{1}` |
| `a ^ b` 或 `a.symmetric_difference(b)` | 对称差集（各自独有的元素） | `{1,2} ^ {2,3}` → `{1,3}` |

---

## 子集 / 超集判断

| 方法 | 作用 | 例子 |
|------|------|------|
| `a.issubset(b)` | a 是否是 b 的子集 | `{1,2}.issubset({1,2,3})` → `True` |
| `a.issuperset(b)` | a 是否是 b 的超集 | `{1,2,3}.issuperset({1,2})` → `True` |
| `a.isdisjoint(b)` | a 和 b 是否没有交集 | `{1,2}.isdisjoint({3,4})` → `True` |

---

## 常见用途：列表去重

```python
lst = [1, 2, 2, 3, 3, 3]
unique = list(set(lst))   # [1, 2, 3]
```
