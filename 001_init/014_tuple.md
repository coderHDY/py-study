# Python 3 元组（tuple）完整语法参考

## 一、创建元组

| 写法 | 说明 | 示例 |
|------|------|------|
| `(1, 2, 3)` | 标准写法 | `t = (1, 2, 3)` |
| `1, 2, 3` | 省略括号（打包） | `t = 1, 2, 3` |
| `(1,)` | 单元素元组，**必须加逗号** | `t = (1,)` → tuple；`(1)` → int |
| `()` | 空元组 | `t = ()` |
| `tuple(iterable)` | 可迭代对象转元组 | `tuple([1,2,3])` → `(1, 2, 3)` |
| `tuple(range(5))` | range 转元组 | `(0, 1, 2, 3, 4)` |

---

## 二、索引 / 切片

语法与 list/str 完全一致：`t[start:stop:step]`

| 操作 | 说明 | 示例（t = (10, 20, 30, 40, 50)） |
|------|------|------|
| `t[i]` | 正向索引（0 起） | `t[0]` → `10` |
| `t[-i]` | 反向索引 | `t[-1]` → `50` |
| `t[1:3]` | 切片 [start, stop) | `t[1:3]` → `(20, 30)` |
| `t[::-1]` | 反转 | `(50, 40, 30, 20, 10)` |
| `t[::2]` | 步长取值 | `(10, 30, 50)` |

---

## 三、运算符

| 操作 | 说明 | 示例 |
|------|------|------|
| `t1 + t2` | 拼接（返回新元组） | `(1,2) + (3,4)` → `(1,2,3,4)` |
| `t * n` | 重复 | `(1,2) * 3` → `(1,2,1,2,1,2)` |
| `x in t` | 成员判断 | `2 in (1,2,3)` → `True` |
| `x not in t` | 不包含判断 | `5 not in (1,2,3)` → `True` |
| `t1 == t2` | 元素逐一比较 | `(1,2) == (1,2)` → `True` |
| `t1 < t2` | 字典序比较 | `(1,2) < (1,3)` → `True` |

---

## 四、内置方法（仅 2 个）

> 元组不可变，因此方法极少

| 方法 | 作用 | 示例 |
|------|------|------|
| `t.count(x)` | 统计 x 出现次数 | `(1,2,1,3).count(1)` → `2` |
| `t.index(x[, start, end])` | 首次出现的索引，找不到抛 ValueError | `(1,2,3).index(2)` → `1` |

---

## 五、常用内置函数

| 函数 | 作用 | 示例 |
|------|------|------|
| `len(t)` | 元素个数 | `len((1,2,3))` → `3` |
| `max(t)` | 最大值 | `max((3,1,2))` → `3` |
| `min(t)` | 最小值 | `min((3,1,2))` → `1` |
| `sum(t)` | 求和 | `sum((1,2,3))` → `6` |
| `sorted(t)` | 排序，返回**列表** | `sorted((3,1,2))` → `[1,2,3]` |
| `reversed(t)` | 反向迭代器 | `tuple(reversed((1,2,3)))` → `(3,2,1)` |
| `enumerate(t)` | 索引+值 | `list(enumerate(('a','b')))` → `[(0,'a'),(1,'b')]` |
| `zip(t1, t2)` | 逐一配对 | `list(zip((1,2),(3,4)))` → `[(1,3),(2,4)]` |
| `any(t)` | 任意元素为真 | `any((0, 1, 0))` → `True` |
| `all(t)` | 全部元素为真 | `all((1, 2, 3))` → `True` |

## 六、解包（Unpacking）

| 写法 | 说明 | 示例 |
|------|------|------|
| `a, b, c = t` | 按顺序解包 | `a,b,c = (1,2,3)` |
| `a, *b = t` | 剩余元素收集到列表 | `a,*b = (1,2,3,4)` → `a=1, b=[2,3,4]` |
| `*a, b = t` | 末尾单独取 | `*a,b = (1,2,3,4)` → `a=[1,2,3], b=4` |
| `a, *b, c = t` | 首尾单独取 | `a,*b,c = (1,2,3,4)` → `a=1, b=[2,3], c=4` |
| `a, (b, c) = 1, (2, 3)` | 嵌套解包 | `b=2, c=3` |
| `_, x, _ = t` | `_` 表示忽略 | `_,x,_ = (1,2,3)` → `x=2` |

## 七、元组与列表互转

| 操作 | 示例 |
|------|------|
| 元组 → 列表 | `list((1,2,3))` → `[1,2,3]` |
| 列表 → 元组 | `tuple([1,2,3])` → `(1,2,3)` |

## 八、嵌套元组

```python
t = ((1, 2), (3, 4), (5, 6))
t[0]       # (1, 2)
t[0][1]    # 2

# 嵌套解包
for x, y in t:
    print(x, y)
# 1 2
# 3 4
# 5 6
```

## 九、命名元组（namedtuple）

```python
from collections import namedtuple

Point = namedtuple('Point', ['x', 'y'])
p = Point(10, 20)

p.x        # 10（属性访问）
p[0]       # 10（索引访问）
p._asdict() # {'x': 10, 'y': 20}
p._replace(x=99)  # Point(x=99, y=20)，返回新对象
Point._fields      # ('x', 'y')
```

## 十、注意事项

| 要点 | 说明 |
|------|------|
| 不可变 | 元组创建后不能增删改元素（但若元素是可变对象，其内容可变） |
| 单元素陷阱 | `(1)` 是整数，`(1,)` 才是元组 |
| 比列表快 | 元组迭代和访问速度略快于列表，适合不变数据 |
| 可哈希 | 元素全为不可变类型时，元组可作为字典 key 或 set 元素 |
| 函数多返回值 | `return a, b` 本质是返回元组 |

```python
# 元组作为字典 key
d = {(0, 0): 'origin', (1, 0): 'right'}
d[(0, 0)]  # 'origin'

# 函数多返回值
def min_max(lst):
    return min(lst), max(lst)

lo, hi = min_max([3, 1, 4, 1, 5])
```
