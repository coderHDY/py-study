# `next()` 与生成器表达式及相关内置函数

## 1) 先看这行代码是什么意思

```python
return next((s for s in self.stu_list if s.name == name), None)
```

拆解：

```
next(
    (s for s in self.stu_list if s.name == name),  # ① 生成器表达式
    None                                            # ② 找不到时的默认值
)
```

---

## 2) 生成器表达式 `(... for ... in ... if ...)`

写法与列表推导式几乎一样，区别：
- 列表推导式 `[...]`：立即生成全部结果放进内存。
- 生成器表达式 `(...)`：**惰性求值**，逐个产出，不占多余内存。

```python
nums = [1, 2, 3, 4, 5]

# 列表推导式：马上生成整个列表
squares_list = [x * x for x in nums]

# 生成器表达式：不立即计算，需要时才产出
squares_gen = (x * x for x in nums)

print(next(squares_gen))   # 1
print(next(squares_gen))   # 4
print(next(squares_gen))   # 9
```

---

## 3) `next(iterator, default)`

- `next(it)` — 取迭代器的下一个值，耗尽时抛 `StopIteration`。
- `next(it, default)` — 耗尽时返回 `default`，不报错（**推荐写法**）。

```python
gen = (x for x in [10, 20])

print(next(gen))          # 10
print(next(gen))          # 20
print(next(gen, "没了"))   # 没了（不报错）
```

**最常见用途：从序列中找第一个满足条件的元素：**

```python
users = [{"name": "张三", "age": 18}, {"name": "李四", "age": 25}]

# 找第一个年龄 > 20 的用户，找不到返回 None
result = next((u for u in users if u["age"] > 20), None)
print(result)   # {'name': '李四', 'age': 25}
```

---

## 4) `iter()` — 手动获取迭代器

```python
lst = [1, 2, 3]
it = iter(lst)       # 把列表变成迭代器

print(next(it))   # 1
print(next(it))   # 2
```

`for` 循环本质上就是先调用 `iter()`，再反复调用 `next()`。

## 5) 相关内置函数

### `any(iterable)` — 有一个为真就返回 True

```python
nums = [0, 0, 3, 0]
print(any(nums))                        # True（有 3）
print(any(x > 10 for x in nums))       # False
```

常用于"检查是否存在满足条件的元素"，比 `for + break` 更简洁：

```python
# 判断列表里有没有叫张三的学生
exists = any(s.name == "张三" for s in stu_list)
```

### `all(iterable)` — 全部为真才返回 True

```python
scores = [80, 90, 75]
print(all(s >= 60 for s in scores))   # True（全部及格）
print(all(s >= 80 for s in scores))   # False
```

### `filter(func, iterable)` — 过滤，返回迭代器

```python
nums = [1, 2, 3, 4, 5, 6]
evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)   # [2, 4, 6]

# 等价的生成器表达式写法（更推荐）
evens2 = [x for x in nums if x % 2 == 0]
```

### `map(func, iterable)` — 映射变换，返回迭代器

```python
nums = [1, 2, 3]
squares = list(map(lambda x: x ** 2, nums))
print(squares)   # [1, 4, 9]

# 等价的列表推导式写法（更推荐）
squares2 = [x ** 2 for x in nums]
```

### `zip(*iterables)` — 并行打包多个序列

```python
names = ["张三", "李四", "王五"]
scores = [90, 85, 92]

for name, score in zip(names, scores):
    print(f"{name}: {score}")

# 打包成字典
result = dict(zip(names, scores))
# {'张三': 90, '李四': 85, '王五': 92}
```

### `enumerate(iterable, start=0)` — 同时拿下标和值

```python
fruits = ["苹果", "香蕉", "橙子"]
for i, fruit in enumerate(fruits, start=1):
    print(f"{i}. {fruit}")
# 1. 苹果
# 2. 香蕉
# 3. 橙子
```

### `sorted(iterable, key, reverse)` — 排序返回新列表

```python
students = [
    {"name": "张三", "score": 85},
    {"name": "李四", "score": 92},
    {"name": "王五", "score": 78},
]

# 按成绩从高到低排
result = sorted(students, key=lambda s: s["score"], reverse=True)
```

### `min()` / `max()` + `key` — 带条件取极值

```python
# 找成绩最高的学生
top = max(students, key=lambda s: s["score"])
print(top)   # {'name': '李四', 'score': 92}
```

---

## 6) 对比速查表

| 需求 | 推荐写法 |
|---|---|
| 找第一个满足条件的元素 | `next((x for x in lst if ...), None)` |
| 判断是否存在满足条件的元素 | `any(... for x in lst)` |
| 判断是否全部满足条件 | `all(... for x in lst)` |
| 过滤出满足条件的元素列表 | `[x for x in lst if ...]` |
| 对每个元素做变换 | `[f(x) for x in lst]` |
| 并行遍历多个列表 | `zip(a, b)` |
| 遍历时需要下标 | `enumerate(lst)` |
| 按某字段排序 | `sorted(lst, key=lambda x: x.field)` |
| 取最大/最小 | `max(lst, key=...)` / `min(lst, key=...)` |
