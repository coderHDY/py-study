# Python 推导式完整知识点

## 1) 四种推导式对比

| 推导式 | 语法 | 结果类型 | 特点 |
|---|---|---|---|
| 列表推导式 | `[expr for x in it if cond]` | `list` | 有序、可重复 |
| 集合推导式 | `{expr for x in it if cond}` | `set` | 无序、自动去重 |
| 字典推导式 | `{k: v for x in it if cond}` | `dict` | key-value 映射 |
| 生成器表达式 | `(expr for x in it if cond)` | `generator` | 惰性求值，省内存 |

```python
nums = [1, 2, 3, 4, 5]

list_comp = [x * 2 for x in nums if x > 2]   # [6, 8, 10]
set_comp  = {x * 2 for x in nums if x > 2}   # {8, 10, 6}  顺序不固定
dict_comp = {x: x * 2 for x in nums if x > 2} # {3: 6, 4: 8, 5: 10}
gen_exp   = (x * 2 for x in nums if x > 2)   # 生成器对象，惰性求值
```

## 2) 列表推导式 `[...]`

**基本语法：**

```python
[表达式 for 变量 in 可迭代对象 if 条件]
```

```python
# 基础：生成平方数
squares = [x ** 2 for x in range(1, 6)]
# [1, 4, 9, 16, 25]

# 带过滤：只要偶数
evens = [x for x in range(10) if x % 2 == 0]
# [0, 2, 4, 6, 8]

# 字符串处理
words = ["hello", "world", "python"]
upper = [w.upper() for w in words]
# ['HELLO', 'WORLD', 'PYTHON']
```

**嵌套循环：**

```python
# 生成坐标对（等价于两层 for 循环）
pairs = [(x, y) for x in [1, 2] for y in [3, 4]]
# [(1, 3), (1, 4), (2, 3), (2, 4)]
```

## 3) 集合推导式 `{...}`

- 写法和列表推导式只差一对括号类型：`{}`。
- 结果自动去重，且无序。
- 元素必须**可哈希**（数字、字符串、元组可以；列表、字典不行）。

```python
users = [
    {"name": "张三", "age": 18},
    {"name": "李四", "age": 25},
    {"name": "王五", "age": 18},
]

# 取出所有 18 岁用户的姓名（集合，自动去重）
age_18_names = {u["name"] for u in users if u["age"] == 18}
# {'张三', '王五'}

# 所有年龄去重
ages = {u["age"] for u in users}
# {18, 25}
```

---

## 4) 字典推导式 `{k: v ...}`

- 大括号内写 `key: value` 两部分，这是与集合推导式的唯一区别。

```python
users = [
    {"name": "张三", "age": 18},
    {"name": "李四", "age": 25},
    {"name": "王五", "age": 18},
]

# 把列表转成 {姓名: 年龄} 字典
name_age = {u["name"]: u["age"] for u in users}
# {'张三': 18, '李四': 25, '王五': 18}

# 带过滤：只保留年龄 >= 20
adults = {u["name"]: u["age"] for u in users if u["age"] >= 20}
# {'李四': 25}

# 字典键值互换
d = {"a": 1, "b": 2, "c": 3}
reversed_d = {v: k for k, v in d.items()}
# {1: 'a', 2: 'b', 3: 'c'}
```

## 5) 生成器表达式 `(...)`

- 写法和列表推导式只差括号类型：`()`。
- **惰性求值**：不会立即生成所有结果，每次只产出一个，内存占用极小。
- 适合数据量大、只需遍历一次的场景。

```python
nums = [1, 2, 3, 4, 5]

gen = (x * 2 for x in nums if x > 2)

print(next(gen))        # 6  （取第一个）
print(next(gen))        # 8
print(next(gen, None))  # 10
print(next(gen, None))  # None（耗尽，不报错）

# 或直接转成列表
gen2 = (x * 2 for x in nums if x > 2)
print(list(gen2))       # [6, 8, 10]
```

**与 `next()` 配合：找第一个满足条件的元素**

```python
# 找第一个年龄 > 20 的用户，找不到返回 None
result = next((u for u in users if u["age"] > 20), None)
# {'name': '李四', 'age': 25}
```

---

## 6) 什么时候用哪种

| 场景 | 推荐 |
|---|---|
| 需要保留顺序、可能有重复值 | 列表推导式 `[...]` |
| 需要去重、不关心顺序 | 集合推导式 `{...}` |
| 需要 key-value 结构 | 字典推导式 `{k: v ...}` |
| 数据量大、只遍历一次 | 生成器表达式 `(...)` |
| 找第一个满足条件的元素 | `next((x for x in ... if ...), None)` |

---

## 7) 注意事项

- `{expr}` 只有一个值 → 集合推导式；`{k: v}` 两个值 → 字典推导式。
- 集合/字典推导式的元素（或 key）必须可哈希，**字典、列表不可哈希**。
- 生成器只能遍历一次，消耗完后再 `next()` 只会返回默认值或报错。
- 推导式内尽量避免复杂逻辑，复杂时拆成普通 for 循环更易读。
